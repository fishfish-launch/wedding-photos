# 結婚式フォト共有アプリ

ゲストがQRコードを読み取り、撮った写真をみんなで共有するWebアプリです。

| ファイル | 役割 |
| --- | --- |
| `index.html` | ゲスト用（撮影・アップロード・みんなのギャラリー） |
| `slideshow.html` | 会場スクリーン用スライドショー（新着優先、右下にQR） |
| `qr.html` | 席や受付に置く印刷用QRカード |
| `download.html` | 全写真の一括ダウンロード（ZIP） |
| `config.js` | 接続先と名前・日付の設定（ここだけ書き換える） |
| `supabase/schema.sql` | データベースと写真置き場の定義 |

## URL

- ゲスト用: `https://<公開先>/index.html?k=<ゲスト用合言葉>`
- 新郎新婦用（写真の非表示ができる）: 上のURLに `&admin=<管理用合言葉>` を付ける
- スライドショー: `https://<公開先>/slideshow.html?k=<ゲスト用合言葉>`（`&qr=0` でQR非表示）
- QRカード: `https://<公開先>/qr.html?k=<ゲスト用合言葉>`
- 一括ダウンロード: `https://<公開先>/download.html?k=<ゲスト用合言葉>`

合言葉はこのリポジトリには書かない（公開リポジトリのため）。


## 仕組み

- フィルムカメラ方式で、1人（スマホ1台）あたり24枚まで。残り枚数が画面に出ます。
  上限を変えるときは Supabase の SQL Editor で `update private.settings set shot_limit = 30;`

- 写真は端末側で長辺2048pxのJPEGに縮小してから送ります（1枚 約0.5〜1MB）。
- 合言葉を知らない人は、一覧の取得もアップロードもできません。
- 他の人の投稿は約8秒ごとに自動で反映されます。
